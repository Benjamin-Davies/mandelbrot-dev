# Mandelbrot Device

A Linux device driver that renders the Mandelbrot set, written in Rust.

## Usage

Dependencies (Fedora): linux-devel, rust

```
$ sudo make modules_install
$ sudo modprobe mandelbrot
$ sudo cat /dev/mandelbrot
```
